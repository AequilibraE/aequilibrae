AequilibraE 2.0
===============

Migrating from AequilibraE 1.X
------------------------------

The good news about migration is that AequilibraE itself will take care of migrating your data
to version 2.0. The bad news, on the other hand, is that the code needs to be migrated manually,
and two versions of Python (3.9 and 3.10) are no longer supported from AequilibraE 2.0's release.



Supported OS and Python versions
--------------------------------

As of this version, AequilibraE only support Python versions 3.11 or newer, in line with other 
scientific computation libraries.

Operating System support has also been changed, with native support available for: Windows, Linux
(x86 and ARM), and MacOS (Arm). Systems using MacOS on x86 processors are no longer supported.
